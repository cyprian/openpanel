---
title: ML Experiment Tracking
description: Track machine learning projects, runs, scalar metrics, images, and visual evaluation tables with OpenPanel.
---

OpenPanel can track machine learning experiments alongside your product analytics. Use ML projects for model families like NAFNet, LaMa, Cosmos, or Iris Segmentation, then create runs for each training job, log metrics, compare results, and inspect visual outputs.

## Create an ML project

Create a new project in OpenPanel and choose **ML** as the project type.

ML projects use the same OpenPanel organization, authentication, project settings, and client credentials as the rest of the platform. The dashboard hides web and app analytics sections that are not useful for experiment tracking, so the project stays focused on runs, metrics, and model evaluation.

## Create client credentials

Create a client with write access from the project settings. The Python SDK uses the client ID and client secret to create runs and send training data.

```bash
export OPENPANEL_API_URL="https://your-openpanel-domain.com"
export OPENPANEL_CLIENT_ID="your-client-id"
export OPENPANEL_CLIENT_SECRET="your-client-secret"
```

For OpenPanel Cloud, use the OpenPanel API URL. For self-hosted OpenPanel, use the public URL of your deployment.

## Install the Python SDK

Install the ML SDK package:

```bash
pip install openpanel-ml
```

If you are using a self-hosted fork before publishing the package, install it from the repository checkout:

```bash
pip install ./packages/sdks/python
```

## Start a run

Use `openpanel.init()` at the start of a training script. The `project` value is the ML project name shown in the dashboard. If the project does not exist yet, OpenPanel creates it for you.

```python
import openpanel.ml as openpanel

run = openpanel.init(
    project="NAFNet",
    name="nafnet-baseline-001",
    tags=["baseline", "64x64"],
    config={
        "model": "NAFNet",
        "learning_rate": 1e-4,
        "batch_size": 16,
        "optimizer": "adamw",
    },
    metadata={
        "dataset": "synthetic-rain",
        "trainer": "pytorch",
    },
)
```

## Log scalar metrics

Call `run.log()` during training to store scalar time-series metrics.

```python
for step in range(1000):
    loss = train_step()
    psnr, ssim = evaluate_batch()

    run.log(
        {
            "loss": loss,
            "psnr": psnr,
            "ssim": ssim,
        },
        step=step,
        epoch=step // 100,
    )
```

OpenPanel stores scalar metrics as time-series data. In the run dashboard, metrics appear as charts with axes, hover tooltips, and final metric summaries.

## Log images

Use `run.log_image()` to upload a single image for a run. Images can be PNG, JPEG, or WebP.

```python
run.log_image(
    "outputs/prediction-0001.png",
    kind="prediction",
    step=120,
    epoch=1,
    caption="Validation prediction",
)
```

Use `every` to reduce upload volume for long training jobs.

```python
run.log_image(
    prediction_png_bytes,
    kind="prediction",
    content_type="image/png",
    every=50,
)
```

## Log visual evaluation rows

Visual evaluation tables are useful when you want to compare input images, ground truth, predictions, error maps, and per-sample metrics in one row.

```python
run.log_evaluation(
    sample_id="val-00042",
    input="samples/input-00042.png",
    ground_truth="samples/gt-00042.png",
    prediction="outputs/pred-00042.png",
    error_map="outputs/error-00042.png",
    metrics={
        "psnr": 34.5,
        "ssim": 0.94,
        "lpips": 0.08,
    },
    step=250,
    epoch=2,
    metadata={
        "split": "validation",
        "scene": "indoor",
    },
)
```

The run page shows evaluation rows in a table with image thumbnails, metric columns, search, sorting, filtering by sample text, and pagination.

## Finish a run

Mark the run as finished when training completes.

```python
run.finish("finished")
```

If a training job fails, mark it explicitly:

```python
run.finish("failed")
```

## Full PyTorch example

```python
import openpanel.ml as openpanel

run = openpanel.init(
    project="Tiny CNN",
    name="tiny-cnn-smoke-test",
    tags=["pytorch", "smoke-test"],
    config={
        "image_size": 64,
        "batch_size": 8,
        "learning_rate": 1e-3,
    },
)

for epoch in range(3):
    for step in range(100):
        loss = train_step()
        psnr = evaluate_psnr()
        ssim = evaluate_ssim()

        run.log(
            {
                "loss": loss,
                "psnr": psnr,
                "ssim": ssim,
            },
            step=epoch * 100 + step,
            epoch=epoch,
        )

        if step % 25 == 0:
            run.log_evaluation(
                sample_id=f"epoch-{epoch}-step-{step}",
                input="input.png",
                ground_truth="ground-truth.png",
                prediction="prediction.png",
                error_map="error-map.png",
                metrics={
                    "psnr": psnr,
                    "ssim": ssim,
                },
                step=epoch * 100 + step,
                epoch=epoch,
            )

run.finish("finished")
```

## What appears in the dashboard

| Dashboard area | What it shows |
| --- | --- |
| Project overview | ML projects and their runs |
| Run list | status, tags, updated time, and run metadata |
| Run detail | final metrics, metric charts, config, metadata, notes, and images |
| Visual evaluation table | input, ground truth, prediction, error map, PSNR, SSIM, LPIPS, epoch, and step |
| Run comparison | overlaid metric charts, hyperparameters, metadata, and final metrics |

## Storage

On self-hosted OpenPanel, uploaded ML images are stored on the server by default. Configure the storage directory with `ML_STORAGE_DIR`.

```bash
ML_STORAGE_DIR=/var/lib/openpanel/ml
```

This keeps artifacts and visual outputs on your own infrastructure. Object storage providers such as Amazon S3 or Google Cloud Storage can be added later behind the same storage abstraction.

## API endpoints

The Python SDK calls the ML HTTP API:

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | `/ml/runs` | Create a run |
| `PATCH` | `/ml/runs/:runId` | Update run status or metadata |
| `POST` | `/ml/runs/:runId/log` | Log scalar metrics |
| `POST` | `/ml/runs/:runId/images` | Upload a run image |
| `POST` | `/ml/runs/:runId/evaluations` | Log a visual evaluation table row |

All endpoints require OpenPanel client credentials.
